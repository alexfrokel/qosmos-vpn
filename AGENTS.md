# Выпуск Qosmos VPN для macOS

При каждом повышении версии в `MacVPN/Info.plist` опубликуйте обновление на GitHub. Отправьте коммит с версией в `main`, дождитесь завершения workflow **macOS release** и проверьте наличие `.pkg`, `.zip` и `qosmos-update.json` в релизе. Обычные изменения без повышения версии можно отправлять без выпуска.

Личные VPN-профили, ключи и локальные сборки не добавляйте в Git.
