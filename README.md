# Qosmos VPN

Клиент VLESS Reality для macOS 26 и новее на Apple Silicon. Импортирует ссылки и клиентский JSON Xray. Системный туннель использует sing-box. В установщик и архив из GitHub Releases входит Python 3.

Kill Switch включён по умолчанию. После обрыва сеанса он оставляет доступ закрытым. Действие **Вернуть доступ** в окне или строке меню снимает блокировку. При ручном отключении блокировка снимается автоматически. Для установки или обновления системной службы macOS может один раз запросить пароль администратора.

## Настройка своего сервера

Отключите VPN, откройте **+ → Настроить свой сервер…** и выберите схему:

- **Один VPS.** Укажите данные SSH. Qosmos установит VLESS Reality и добавит профиль.
- **Вход и выход.** Укажите данные SSH обоих VPS или вставьте прямую ссылку VLESS Reality с публичным IPv4 готового выхода. Qosmos настроит вход по SSH и добавит профиль. Сайты будут видеть IP выхода.

Для установки нужен Debian 12+ или Ubuntu 22.04+ с systemd на x86-64 или ARM64 и доступ по SSH от root или пользователя с sudo без запроса пароля. В панели хостинга разрешите TCP-порт VPN на выходе, по умолчанию 443. Для входа достаточно доступного с Mac порта SSH. Перед установкой сверьте отпечатки SSH в панели или консоли VPS. Пароли для установки не сохраняются. Для повторных подключений через вход используется отдельный ключ на Mac.

## Vezde VPN для macOS

Vezde VPN — отдельное приложение для подключения по подписке. У него собственный идентификатор, настройки и запись в Связке ключей. Vezde и Qosmos используют одну системную службу и могут быть установлены одновременно. Служба обслуживает одно активное VPN-подключение. Пока оно занято, Vezde показывает статус и позволяет активировать подписку.

```sh
QOSMOS_ENGINE_DIR="$PWD/.vless-local/engines" VezdeVPN/build.sh
```

Сборка создаёт `VezdeVPN/build/Vezde VPN.app`. Она подключается к локальному демо-шлюзу на `127.0.0.1:8765`. Чтобы использовать удалённый шлюз, передайте его HTTPS-адрес в `VEZDE_VOX_API_URL` при сборке. В режиме «Авто» при новом подключении приложение пробует рабочие локации, начиная с последней успешной. Трафик за календарный месяц и количество занятых устройств поступают из шлюза. Для этих данных запустите обновлённый `Server/vox_demo.py`.

В разделе «Протокол» доступны VLESS + REALITY, WireGuard и AmneziaWG, если выбранная локация их поддерживает. Сборка Vezde требует Go 1.25 или новее для сборки Amnezia Box. При первом подключении по WireGuard или AmneziaWG приложение обновляет системную службу.

В **Настройки → Обновления** Vezde проверяет свой канал на GitHub. Автопроверку при запуске можно включить в том же разделе. [Инструкция выпуска Vezde](VezdeVPN/updates/README.md).

## Демо-подписка Vox на Mac

Тестовая сборка использует отдельный шлюз, который проверяет `demo: true` в Vox. Выпустите код один раз для тестового пользователя и запустите шлюз. SQLite хранится локально вне репозитория. Ключ Vox вводится в терминале скрыто или передаётся шлюзу через `QOSMOS_VOX_DEMO_KEY`.

```sh
python3 Server/vox_demo.py --database /private/tmp/qosmos-vox-demo.sqlite3 issue qosmos-demo-mac-01
python3 Server/vox_demo.py --database /private/tmp/qosmos-vox-demo.sqlite3 serve
```

Соберите Qosmos с адресом шлюза. Для удалённого шлюза укажите его HTTPS-адрес. Локальный HTTP разрешён только на `127.0.0.1`.

```sh
QOSMOS_VOX_API_URL=http://127.0.0.1:8765 \
  QOSMOS_ENGINE_DIR="$PWD/.vless-local/engines" MacVPN/build.sh
```

Для существующего демо-подписчика почту и дату окончания можно сохранить в той же базе. Команда сохраняет код активации и привязанные устройства.

```sh
python3 Server/vox_demo.py --database /private/tmp/qosmos-vox-demo.sqlite3 \
  profile qosmos-demo-mac-01 --email demo@example.com --expires-at 2026-12-31T21:00:00Z
```

В Vezde нажмите **Активировать подписку**, в Qosmos откройте **+ → Подписка Vox**. Введите код из команды `issue`, выберите страну и нажмите **Подключить**. Включение повторно запрашивает профиль выбранной страны для этого Mac. Код активации хранится в Связке ключей. Ручные профили доступны в списке профилей.

## Сборка и релиз

```sh
MacVPN/fetch-engines.sh .vless-local/engines
QOSMOS_ENGINE_DIR="$PWD/.vless-local/engines" MacVPN/build.sh
```

Сборка использует общую конфигурацию туннеля из исходников. Локальные профили, ключи и ранее собранные приложения в репозиторий не входят.

Чтобы выпустить обновление, повысьте версию и номер сборки в `MacVPN/Info.plist` и отправьте коммит в `main`. GitHub Actions сравнит версию с последним релизом, создаст тег `v<версия>` и опубликует установщик `.pkg`, архив `.zip` и манифест `qosmos-update.json` с контрольной суммой SHA-256. Если сборку нужно повторить, запустите workflow **macOS release** вручную для `main`.

В настройках Qosmos нажмите «Проверить сейчас», затем «Обновить». Приложение проверит архив, заменит текущую копию и запустится снова. Для установки из приложения начиная с 1.9.3 нужен выпуск с контрольной суммой в манифесте. Для локальной сборки можно передать адрес доверенного источника через `QOSMOS_UPDATE_SOURCE` или указать его в настройках приложения.

Релизы используют локальную подпись (ad hoc). Подпись Developer ID и нотариальное заверение Apple для публичной раздачи ещё не настроены.
