# Qosmos VPN

Клиент VLESS Reality для macOS 26 и новее на Apple Silicon. Импортирует ссылки и клиентский JSON Xray. Системный туннель использует sing-box. В установщик и архив из GitHub Releases входит Python 3.

Kill Switch включён по умолчанию. После обрыва сеанса он оставляет доступ закрытым. Действие **Вернуть доступ** в окне или строке меню снимает блокировку. При ручном отключении блокировка снимается автоматически. Для установки или обновления системной службы macOS может один раз запросить пароль администратора.

## Настройка своего сервера

Отключите VPN, откройте **+ → Настроить свой сервер…** и выберите схему:

- **Один VPS.** Укажите данные SSH. Qosmos установит VLESS Reality и добавит профиль.
- **Вход и выход.** Укажите данные SSH обоих VPS или вставьте прямую ссылку VLESS Reality с публичным IPv4 готового выхода. Qosmos настроит вход по SSH и добавит профиль. Сайты будут видеть IP выхода.

Для установки нужен Debian 12+ или Ubuntu 22.04+ с systemd на x86-64 или ARM64 и доступ по SSH от root или пользователя с sudo без запроса пароля. В панели хостинга разрешите TCP-порт VPN на выходе, по умолчанию 443. Для входа достаточно доступного с Mac порта SSH. Перед установкой сверьте отпечатки SSH в панели или консоли VPS. Пароли для установки не сохраняются. Для повторных подключений через вход используется отдельный ключ на Mac.

## Сборка и релиз

```sh
MacVPN/fetch-engines.sh .vless-local/engines
QOSMOS_ENGINE_DIR="$PWD/.vless-local/engines" MacVPN/build.sh
```

Сборка использует общую конфигурацию туннеля из исходников. Локальные профили, ключи и ранее собранные приложения в репозиторий не входят.

Чтобы выпустить обновление, повысьте версию и номер сборки в `MacVPN/Info.plist` и отправьте коммит в `main`. GitHub Actions сравнит версию с последним релизом, создаст тег `v<версия>` и опубликует установщик `.pkg`, архив `.zip` и манифест `qosmos-update.json` с контрольной суммой SHA-256. Если сборку нужно повторить, запустите workflow **macOS release** вручную для `main`.

В настройках Qosmos нажмите «Проверить сейчас», затем «Обновить». Приложение проверит архив, заменит текущую копию и запустится снова. Для установки из приложения начиная с 1.9.3 нужен выпуск с контрольной суммой в манифесте. Для локальной сборки можно передать адрес доверенного источника через `QOSMOS_UPDATE_SOURCE` или указать его в настройках приложения.

Релизы используют локальную подпись (ad hoc). Подпись Developer ID и нотариальное заверение Apple для публичной раздачи ещё не настроены.
