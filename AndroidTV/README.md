# Qosmos VPN для Android TV

Приложение управляется пультом и поддерживает Android TV 14, а также более ранние версии начиная с Android 8. APK включает ARM, ARM64 и x86-64. Для VPN используются прямые профили VLESS Reality по TCP.

## Установка и привязка телевизора

1. Подключите Mac и телевизор к одной сети. На телевизоре включите параметры разработчика и беспроводную отладку.
2. Если Mac ещё не сопряжён, откройте на ТВ «Сопряжение по коду» и выполните `adb pair IP:ПОРТ`, введя показанный код на Mac. Порт подключения на основном экране беспроводной отладки обычно отличается от порта сопряжения. На моделях с сетевой отладкой подтвердите запрос ADB на телевизоре.
3. Из папки `AndroidTV` выполните:

   ```bash
   ./install-tv.sh IP:ПОРТ_ПОДКЛЮЧЕНИЯ
   ```

   Команда устанавливает APK из `dist`, открывает каталог на ТВ и добавляет открытый ключ этого телевизора в закрытый репозиторий. Для привязки на Mac нужен `gh`, авторизованный с правом записи в закрытый репозиторий. ADB берётся из локального SDK, `ANDROID_HOME` или переменной `ADB`. Если APK уже установлен, выполните `./enroll-catalog.sh IP:ПОРТ_ПОДКЛЮЧЕНИЯ`.

После привязки отладку можно выключить. Откройте **Настройки → Загрузить конфиг**, выберите профиль пультом и нажмите **Подключить**. При первом подключении подтвердите системное разрешение Android.

## Управление каталогом

Исходные ссылки хранятся в `profiles/*.txt` закрытого репозитория `alexfrokel/qosmos-tv-configs`. После изменения профилей или списка устройств GitHub Actions публикует зашифрованный каталог. Каждый телевизор получает ключ каталога, зашифрованный для его ключа из Android Keystore. Открытие каталога в Qosmos автоматически запрашивает текущий список.

Для нового телевизора или после очистки данных приложения повторите привязку. Удаление открытого ключа устройства из `devices/` отключает доступ к будущим выпускам каталога. Для отзыва уже скачанного VPN-профиля удалите его пользователя на VPN-сервере.

## Локальная сборка

Нужны Java 17, Android SDK API 35, Build Tools 35.0.0, Android NDK 28.2.13676358, Go и Xcode Command Line Tools для иконки. Скрипты берут SDK и Java из `.build/tools` или из `ANDROID_HOME` и `JAVA_HOME`.

```bash
./build-engine.sh
./build.sh
```

Сборка использует sing-box v1.14.4 и локальный ключ подписи. Для обновления поверх установленной копии сохраняйте `.build/qosmos-tv-local.p12`. Для ручного импорта через `send-profile.sh` нужна сборка `QOSMOS_TV_DEBUG=1 ./build.sh`. Для каталога отладочная сборка не требуется.
