# Qosmos VPN для Android TV

Приложение управляется пультом и поддерживает Android TV 14, а также более ранние версии начиная с Android 8. APK включает ARM, ARM64 и x86-64. Для VPN используются прямые профили VLESS Reality по TCP.

## Установка

Передайте персональный APK на телевизор через USB-накопитель или локальную отправку файлов и откройте его на телевизоре. Если Android запросит разрешение на установку для файлового менеджера, подтвердите его. Если Mac уже подключён к телевизору по ADB, можно выполнить `./install-tv.sh IP:ПОРТ` из папки `AndroidTV`.

После установки откройте **Настройки → Загрузить конфиг**, выберите профиль пультом и нажмите **Подключить**. При первом подключении подтвердите системное разрешение Android.

## Управление каталогом

Исходные ссылки хранятся в `profiles/*.txt` закрытого репозитория `alexfrokel/qosmos-tv-configs`. После изменения профилей GitHub Actions публикует зашифрованный каталог. При открытии списка приложение автоматически загружает последнюю версию.

Ключ расшифровки входит в персональный APK, поэтому передавайте файл только тем, кому предназначен доступ к профилям. Не публикуйте персональный APK в открытом релизе. Смена ключа каталога требует новой персональной сборки. Для отзыва уже полученного профиля удалите его пользователя на VPN-сервере.

## Локальная сборка

Нужны Java 17, Android SDK API 35, Build Tools 35.0.0, Android NDK 28.2.13676358, Go и Xcode Command Line Tools для иконки. Скрипты берут SDK и Java из `.build/tools` или из `ANDROID_HOME` и `JAVA_HOME`.

```bash
./build-engine.sh
QOSMOS_TV_CATALOG_KEY_FILE=/защищённый/путь/к/ключу ./build.sh
```

Файл ключа содержит 32 байта в Base64 и должен соответствовать секрету `QOSMOS_CATALOG_KEY` в закрытом репозитории. Персональная сборка сохраняется в `dist/Qosmos-TV-Personal.apk`. Сборка без параметра создаёт `dist/Qosmos-TV.apk` с ручным добавлением подписок. Для ручного импорта через `send-profile.sh` нужна сборка `QOSMOS_TV_DEBUG=1 ./build.sh`.

Сборка использует sing-box v1.14.4 и локальный ключ подписи. Для обновления поверх установленной копии сохраняйте `.build/qosmos-tv-local.p12`.
